# 🎮 Tetris HomeLab Edition

A Python/Pygame Tetris game with user accounts, an online leaderboard, and a HomeLab server.

## 👨‍💻 About Me

Hi, I'm **Saeed**.

I'm new to programming and game/server development, and this project is part of my journey to learn by actually building things.

The main idea behind this project is bigger than just making a Tetris game. I'm trying to learn how to build and run my **own game server**, connect a game to that server, handle user accounts, store scores, and eventually build a more complete multiplayer/game-server system.

I'm still learning, so this project isn't perfect. A lot of it is experimentation, debugging, and figuring things out as I go.

## 🎯 What I'm Trying to Learn

- Python programming
- Pygame game development
- Client/server communication
- REST APIs
- User authentication
- Leaderboards
- Running my own HomeLab server
- Linux and server administration
- Building Windows executables
- Git and GitHub
- Eventually, building a complete game server

## 🚀 The Goal

Tetris is basically my starting point.

The long-term goal is to take what I learn from this project and use it to build a proper game with my own server infrastructure.

I'm learning as I build, so the project will probably change and improve over time.

Download **tetris.exe** from this repository and run it on Windows.
